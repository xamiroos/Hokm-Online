HOKM - GitHub Pages release package

Deploy:
1. Create a new GitHub repository (e.g. hokm-game).
2. Upload index.html, .nojekyll and this README to the repository root.
3. Open Settings > Pages.
4. Under Build and deployment, select Deploy from a branch.
5. Choose branch main and folder /(root), then Save.
6. Wait for deployment and open https://YOUR-USERNAME.github.io/REPOSITORY-NAME/

This is a static HTML demo. It does not provide shared real-time multiplayer rooms; that requires a backend/realtime service.
